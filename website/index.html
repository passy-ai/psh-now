FAQs

          

            

              What is psh.now?
              
One hub for the agents that need a decision. Local, remote, or sandboxed, they ask here, and you or a teammate approve, deny, or clarify from any device.

            

            

              Why not just let the agent wait in the terminal?
              
Because you lose track. A terminal prompt blocks the agent and you end up swapping windows to find who's stuck. psh.now holds the request open and drops it into one queue you can check from anywhere.

            

            

              What can an agent ask?
              
Three kinds of request: a command to run, an action to take, or a question to answer. Approve or deny, and whatever reason you attach travels back to the agent in the response, so an open question comes back answered in words, not just as a yes.

            

            

              Is my code sent to psh.now?
              
No. An agent sends the step that needs you (a title and a short message), not your codebase. The gateway stores the request only while it's open, and once it's answered or times out the request data is deleted. It never sees your files, and the agent keeps its own credentials.

            

            

              How is this different from YOLO mode or auto-approve?
              
YOLO mode says yes to everything, including the rm and the deploy. psh.now risk-scores every request first (recursive deletes, force pushes, DROP TABLE, terraform destroy, deploys, sudo) and shows you why it was flagged instead of a wall of shell. You decide; nothing is auto-approved for you.

            

            

              What are permission hooks?
              
The place your agent normally pauses for a yes: Claude Code's permission prompt, Codex's approval gate, Cursor's confirmation. A hook is what lets psh.now intercept that pause and turn it into a request you can answer from anywhere. There's a ready-made Claude Code hook, plus a CLI (psh hook) that reads JSON on stdin for anything else.

            

            

              Does it work with my agent?
              
All of them. psh.now is an agnostic skill: any agent that can make an HTTP request works, including Claude Code, Codex, Cursor, Cline, Gemini CLI, OpenClaw, or your own script. There's also a CLI: psh ask "…" --title "…".

            

            

              What does it cost?
              
Nothing to start, and no account needed. Connect an agent, pair a device, and answer. There's no trial clock and no card.

            

            

              What if nobody answers?
              
Every request has a window: 90 seconds by default, configurable per deployment. Unanswered means declined, so a forgotten prompt never turns into a surprise. The agent gets a clear "not approved" and can adapt.

            

            

              Do I need an account?
              
No. Connect an agent and pair a device, and you're answering questions. Create an account when you want the workspace to persist or to invite a team.

            

            

              How do I answer from my phone or tablet?
              
Pair each device once with a simple link. It's an installable PWA, so the dashboard travels with you. Open it on your phone and the request is waiting there, still open, until you decide. Push notifications aren't in yet, so the dash is where you answer.

            

            

              Can someone else on my team answer for me?
              
Yes. Invite teammates to a channel and whoever is free can approve, deny, or clarify. Every decision is logged against the person who made it.

            

            

              Can agents approve each other's work?
              
Yes. A central agent can hold a scoped key on the channels you trust and answer on your behalf, escalating to a human whenever it isn't sure.

            

            

              I'm an agent, what should I do first?
              
Paste the prompt from the Copy prompt for agent button at the top of this page. It is one command: it installs psh.now as a skill and runs the setup, and if npm or git is missing it falls back to curl -fsSL https://psh.now/install.sh -o /tmp/psh-install.sh && bash /tmp/psh-install.sh. Then read the docs at https://psh.now/docs and route your questions through psh.now.
