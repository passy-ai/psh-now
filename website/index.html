Approve, deny, or clarify

          

            What a request can carry, where it can be answered, and who is allowed to answer it.
          


          

            
One queueEvery agent posts to the same workspace, so a request is a row you can find later instead of a prompt that dies with the terminal.

            
Any devicePhone, tablet, desktop, or the notch. The dashboard is an installable PWA and web push works once notifications are allowed.

            
TeamInvite people to a channel. Anyone in it can decide, and the decision records which member answered.

            
Answer in wordsThe reply text comes back to the agent inside the response, so a question can be answered in a sentence instead of a yes.

            
Ask-only keysAn agent's key can request a decision and cannot make one. Limited to a single channel, it can only ask there.

            
ChannelsRequests are grouped by channel, so one project's history stays readable and separate from the next.

          

        


          

        

        
          

        

        
        

          
MIT LICENSED, SELF-HOSTABLE

          
Run this server yourself


          

            

              One endpoint. One decision in the response.
            

            

              The gateway is a Bun service with a Postgres database; docker compose up in the
              repository starts both. Self-hosted, nothing passes through this host: requests, keys and
              history stay in your own database, and you decide how long they are kept.
            

            

              Setup is on the self-hosting page. The source is
              github.com/passy-ai/psh-now, under the MIT licence.

FAQs

          

            

              What is psh.now?

A server that holds an approval request open while an agent waits on it. The agent makes one HTTP call, a person approves, denies or answers from a phone, a browser or the notch, and the call returns with that decision.

            

            

              Why not let the agent wait in the terminal?

That prompt is only visible in that one terminal. If you closed the window, the agent stays blocked until you go back to it. A request in psh.now can be answered from every device you have paired.

            

            

              What can an agent ask?

A command to run, an action to take, or a question with a text answer. One request is one decision: a message that lists several options is rejected, because a single tap cannot answer it.

            

            

              Is my code sent to psh.now?

No. A request is a title, a message and, if the agent includes it, the command line. Your files stay on your machine. The request and its decision are kept in your workspace history, or in your own database when you self-host.

            

            

              How is this different from YOLO mode or auto-approve?

Auto-approve never asks. psh.now asks about the requests you route to it, and labels the dangerous ones from the command text: rm -rf, force push, DROP TABLE, terraform destroy, sudo, deploys. The label says why it was flagged. You still decide.

            

            

              What are permission hooks?

The point where an agent would stop for a yes: Claude Code's permission prompt, Codex's approval gate, Cursor's confirmation. The hook turns that stop into a request. There is a ready-made Claude Code hook, and a psh hook command that reads JSON on stdin for anything else.

            

            

              Does it work with my agent?

Any client that can send an HTTP POST. The agents pages carry the setup for a dozen harnesses, the CLI does the same with psh ask, and a client that only speaks MCP can use https://psh.now/mcp.

            

            

              What does it cost?

Free to start, with no account and no card. An approval costs two requests, one in and one out; a request that expires or is cancelled costs nothing. Docs lists the limits for each plan, and /pricing is the markdown version for agents.

            

            

              What if nobody answers?

The window is 90 seconds by default and 15 minutes at most. When it closes the request expires, and the agent's call returns status expired, which is not an approval.

            

            

              Do I need an account?

No. Post a request and pair a device. An account keeps the workspace and its history after the anonymous allowance is used up.

            

            

              How do I answer from my phone or tablet?

Open /app on the device and add it to the home screen; it is a PWA, and web push works once you allow notifications. Pairing a device takes one link from the dashboard.

            

            

              Can someone else on my team answer for me?

Yes. Members of a channel can decide any request in it, and the decision records which member answered.

            

            

              Can agents approve each other's work?

Not with an agent key. Keys minted for agents can ask and cannot decide, and a decision needs a person signed in or the account key, which also manages the account. A key can be limited to one channel, so an agent's requests stay there.

            

            

              I'm an agent, what should I do first?

Read /skill.md, or paste the prompt from the Copy prompt button at the top of this page into your agent. It installs the skill, writes the rule into agents.md, and keeps the key in PSH_API_KEY.
