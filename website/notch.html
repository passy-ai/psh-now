What it does while you are not looking

The point of the notch is that it is where attention already lands, so the app is built around that one surface rather than around a window.

It opens itself

A request opens the notch with a ping, and it withdraws after five seconds unless the pointer is on it.

Live, not polled

One websocket per Mac. An answer from your phone closes the card here, and a new ask never needs a refresh.

Quiet on command

Hide the notch or mute the ping from the menu. Both keep counting, so nothing is lost and the list is right when it comes back.

No window, no Dock icon

A menu bar app. The queue, Settings and Quit live behind the item, and the bar never changes size when a request arrives.

Over any Space

It follows you across Spaces and sits above full-screen apps, so the answer is in reach on the display you are already using.

A token, not your account

Pairing mints a device token with approve scope, and revoking it on the Devices page ends that Mac's access.

Install it in a minute

  1. Download it

    Take the dmg from the latest release, open it, and drag psh notch to Applications. It is about 210 KB.

  2. Open it once, on purpose

    macOS refuses the first launch of an app it cannot notarise. Right-click the app, choose Open, and confirm. That is asked once, and it is the whole of the friction: the app is signed ad hoc, with no Developer ID behind it.

  3. Connect this Mac

    Click the item in the menu bar, then Settings, then Connect this Mac. Your browser opens on the dashboard you are signed in to; press Connect psh notch there and the notch writes its token and says live.

  4. Keep it around

    Settings, then Open at login. To take it off a Mac, use Disconnect in the same menu, and revoke the device on the dashboard's Devices page.

Rather build it?

It is one file and one command, with Xcode Command Line Tools already in place. 

cd tools/psh-notch
swiftc -parse-as-library -swift-version 5 -O -o psh-notch PSHNotch.swift
./psh-notch --pair https://psh.now/pair/<token> --name "MacBook Air"

The pairing link is single use and expires quickly; the Devices page mints a fresh one each time. The account secret never reaches the app: the browser spends it to mint a device token, and the app only ever writes that token, at ~/.config/psh-notch/device.json, readable by you alone.

Small on purpose

Everything the notch needs is in one Swift file and the AppKit that ships with macOS. There is no helper process, no background service, and nothing to keep up to date.
