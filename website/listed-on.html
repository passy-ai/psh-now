Listing kit

For a directory editor adding psh.now. The text below is the current description; copy it as it stands.

  • Name: psh.now
  • Tagline: Approve what your AI agent does next, from your phone
  • One paragraph: psh.now is an approval hub for AI agents. An agent posts the step it is about to take as one HTTP request (or one MCP tool call) and the call stays open; a person approves, denies or answers in words from a phone, a browser or the macOS notch, and the call returns with that decision. Keys can be scoped to a channel so another agent can answer there, and the code is MIT licensed.
  • Categories: Developer Tools, AI, Productivity, Open Source
  • Tags: ai-agents, human-in-the-loop, approvals, agent-permissions, claude-code, codex, cursor, mcp, self-hosted, open-source
  • Licence: MIT. Pricing: free to start, no account and no card; an approval costs two requests, and a prepaid package of 10,000 requests is 50 EUR.
  • Logo: 512×512 PNG. Social image: 1200×630 PNG.
  • Website: https://psh.now, Repository: https://github.com/passy-ai/psh-now
