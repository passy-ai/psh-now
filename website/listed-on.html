  • Tagline: Approve what your AI agent does next, from your phone
  • One paragraph: psh.now is the human-approval hub for AI agents. The agent sends a short title and message over one HTTP call (or one MCP tool) and blocks. You answer on any device: approve, deny, or type an answer to a question. The agent gets a boolean back and continues, so work that would have stalled overnight finishes. Keys are ask-only, channels are shared with a whole team, and the code is MIT.
