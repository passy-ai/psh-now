Not listed?

The skill is a folder of shell scripts, so anything with a terminal can use it. Run the same line and check with psh status: 

npx skills add passy-ai/psh-now-skill -g -y

What every page has in common

  • One channel answers every agent, and many people can answer one channel.
  • Ask-only keys for agents: they can request an approval and never grant one.
  • Blocks until answered - no polling loop to write, no webhook to host.
  • Open source, MIT: the same code runs self-hosted, and the hooks are readable.
