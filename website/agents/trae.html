Trae + psh.now

Every step Trae takes can wait for your approval, answered from a phone, a browser or the notch.

Trae reads skills from ~/.trae/skills. A channel groups the requests, and every agent that joins it posts to the same page.

Install it

Either command installs the skill.

npx skills add passy-ai/psh-now-skill -g -y
curl -fsSL https://psh.now/install.sh | sh

It lands in ~/.trae/skills/psh-now, the directory Trae reads. The same install also writes the shared skills directory, so the other agents on the machine get it from one command.

Connect a channel

Open the dashboard, copy the connect prompt from a channel card, and give it to Trae. The link carries the channel, and the key that comes back is scoped to that channel, so every request it posts lands there and a person still decides. 

I'd like you to use psh.now and join this channel: https://psh.now/c/<channel>

What it asks with

One command, and it posts the step the agent is about to take:

psh ask "Deploy the new build?" "This pushes to production."

The call stays open until someone answers or the window closes: 90 seconds by default, 15 minutes at most. An expiry returns status expired, which is not an approval.

Ask or gate

A skill is an ask: the model may skip it. If your setup exposes hooks, wire psh hook, which reads JSON on stdin, and the same call becomes a gate. Claude Code has a ready-made permission hook: see its hook.

Check it works

psh status

It prints the host, auth ✓ and the plan. psh doctor checks further: the skill path, the keys and the workspace.
