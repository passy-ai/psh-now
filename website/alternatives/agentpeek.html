An open source alternative to AgentPeek

AgentPeek is a Mac app for coding agent sessions: the notch, the menu bar, a floating pill, token spend. psh.now is one HTTP call that stays open until a person approves it, denies it, or answers it in words, from a phone, a browser or the macOS notch app. Most teams can run both.

What AgentPeek does

The AgentPeek details below come from agentpeek.app and its docs, read on 11 November 2026. Their site is the source of truth if something here has gone stale.

A Mac app, no server

macOS 14 or newer on Apple silicon. The interface is the notch, the menu bar and a floating pill. No server to run, no account to create.

One-time purchase, one seat per Mac

$14.99 for one Mac, $24.99 for two, $34.99 for three. A 3-day trial per machine, no subscription. A seat is a physical Mac.

26 agents in one window

Claude Code, Codex, Cursor, Copilot, Cline, Aider, Goose, Qwen, Kimi, Devin and others, each with a documented host matrix of what it supports.

More than approvals

Token usage and rate-limit windows with budget alerts, local dev servers, quick routes into configs, saved shell actions, widgets and an agent board.

Where the two differ

They overlap on one thing: answering a permission prompt. The rows below cover the rest, including where AgentPeek is the better fit.

What runs it

psh.nowA hosted server or your own, and any browser, including an installed PWA

AgentPeekA Mac app: macOS 14+, Apple silicon

Where you answer

psh.nowAny device: phone, tablet, another laptop, a browser tab, or the macOS notch app

AgentPeekThe notch, the menu bar or the panel on that Mac

Who can answer

psh.nowEvery member of a channel, and the decision records which member answered

AgentPeekYou, at the machine the agents run on

Agents on other machines

psh.nowYes. A cron job in a container and a laptop post to the same channel

AgentPeekOne Mac at a time; a seat is a physical machine

Scope

psh.nowOne request, one decision: approve, deny, or answer in words

AgentPeekSessions, permissions, prompts, token spend, servers, routes, actions, widgets

Token and budget tracking

psh.nowNone

AgentPeekRate-limit windows, totals, gauges, budget alerts

Self-hosting

psh.nowdocker compose up: a Bun service and Postgres, data in your own database

AgentPeekNot applicable: the app is local by design

Licence

psh.nowMIT, for the server, the CLI and the skill

AgentPeekProprietary, one-time licence, updates included while supported

Price

psh.nowFree to start, no account and no card. An approval costs two requests, one in and one out; a prepaid package of 10,000 costs 50 EUR

AgentPeek$14.99 once for one Mac, up to $34.99 for three

How an agent asks

psh.nowOne POST to /api/v1/approvals with an x-psh-key header, and the call stays open

AgentPeekThe agent runs under a supported host, and AgentPeek reads its session

Pick AgentPeek when

You are at the Mac all day

Several sessions in the notch, answered with a keystroke, beat switching to a browser tab and back.

You want the spend view

Rate-limit windows and budget alerts per agent, in the same window as the approvals. psh.now does not track spend.

A one-time price suits you

One payment, no account, no subscription, no server to keep alive. For one developer on one Mac, that is the whole cost.

You want the whole toolkit

You also get session transcripts, follow-up prompts, dev servers and widgets on any display, all in one app.

Pick psh.now when

The approver is not at that Mac

A deploy at night, a question while you are on a train, a teammate covering for you. The dashboard is a URL, and web push reaches a phone once notifications are allowed.

Several people share the on-call

One channel per project, any member can decide, and the decision records who did.

Agents run somewhere you do not sit

A CI runner, a cron job, a container on a server. Each one needs a single HTTP call, whatever machine it runs on.

You want to read and host the code

MIT. A Bun service and Postgres, started with docker compose up, and requests, keys and history stay in your own database.

What psh.now does not do

These are the things psh.now does not do, so you can judge whether the rest matters to you.

  • No spend tracking. No token counts, no rate-limit windows, no budget alerts. psh.now records decisions.
  • No session monitoring. It never sees the agent's transcript, only the question the agent chose to ask.
  • No session view. The surfaces are the dashboard, the installable PWA and the macOS notch app. There is no session list, no transcript pane and no agent board.
  • No local tooling. No dev-server list, no quick routes, no saved shell actions.

If you work at one Mac and want the session view, AgentPeek covers more. If the person who has to say yes is somewhere else, psh.now covers that.
