# psh-now

This package is a **name reservation**. It contains no code.

psh.now is human approval for AI agents: an agent blocks on a decision, you approve,
deny or answer it from your phone or the macOS notch.

- Install: `curl -fsSL https://psh.now/install.sh | bash`
- Docs: https://psh.now/docs
- Browser SDK: https://www.npmjs.com/package/psh-now-sdk
- Self-hostable relay: https://www.npmjs.com/package/psh-now-relay
- Source: https://github.com/passy-ai/psh-now

The name is held so nobody else can publish under it and pass their code off as
psh.now. If you landed here looking for something to run, none of it is in this
package.
